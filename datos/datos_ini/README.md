# Datos originales

Ejecuta `python fuentes/obtener_datos.py` desde la raíz del repositorio para descargar el CSV y la ficha de Bitext de la revisión fijada en `datos/dataset.lock.json`.

Los archivos descargados se excluyen de Git: el repositorio entrega el script reproducible, la versión de origen, los hashes y la documentación. No agregues aquí tickets privados de clientes.
